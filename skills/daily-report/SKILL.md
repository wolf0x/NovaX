# 系统日报技能

当用户要求"日报"、"系统报告"或类似巡检需求时，按以下步骤执行：

1. 使用 `sys_execute` 依次收集：
   - `df -h /`（磁盘使用）
   - `free -h`（内存使用）
   - `uptime`（系统负载）
2. 使用 `task_plan` 规划（如步骤≥3），每步完成后 `task_update`。
3. 将结果整理为 Markdown 表格输出，包含：指标、当前值、健康状态评估。
4. 若任何指标异常（磁盘 >85%、内存 >90%），用 **加粗** 突出提示。
